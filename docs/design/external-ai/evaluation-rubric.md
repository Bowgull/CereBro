# External AI Output Rubric

Use this checklist before bringing any external AI output into CereBro.

## Reject Immediately

- Requires payment.
- Requires card-backed free trial.
- Redesigns the mockup.
- Uses a generic SaaS/browser look.
- Compresses the left rail.
- Makes bookmarks decorative instead of clickable.
- Uses the mockup as a static background only.
- Ignores the loaded-page state.
- Produces code that cannot be reviewed.

## Accept For Reference

- Gives useful measurements.
- Names reusable components.
- Produces assets that match the mockup.
- Identifies spacing or layout we missed.
- Produces React/Tailwind that can be mined safely.

## Accept For Production Only After Review

- Real components are accessible.
- Click targets match visible UI.
- Browser Home and loaded-page states share one component system.
- Installed-app screenshots improve against both approved targets.
- Tests still pass.
