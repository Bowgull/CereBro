# Screenshot-To-Code Prompt

Use the attached CereBro Browser Home mockup as a strict reference.

Generate React + Tailwind code that reconstructs the layout and component hierarchy.

This is reference code only. Production integration will be done separately.

## Hard Rules

- Do not redesign.
- Do not use generic browser UI.
- Do not use a screenshot as a background.
- Build real components.
- Match rail width, tab strip, omnibox, medallions, cards, panels, and Aang dock.
- Preserve dark stone, brass bevels, green glow, and parchment text.
- Loaded-page state must keep this same chrome.

## Output

1. Component hierarchy.
2. React component code.
3. Tailwind class strategy.
4. Any generated CSS variables.
5. Notes about uncertain measurements.
