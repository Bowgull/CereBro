# Google Stitch Prompt

Use the attached CereBro Browser Home mockup as the exact product UI reference.

Do not redesign it. Do not modernize it. Do not simplify it into a normal SaaS dashboard.

The goal is to extract a production UI system that can be implemented in React and Tailwind.

## Required Output

1. Component inventory.
2. Measured layout grid.
3. Left rail dimensions and item spacing.
4. Title strip and tab strip dimensions.
5. URL/search bar dimensions.
6. Shield, utility, and icon-button states.
7. Pinned medallion component.
8. Bookmark card component.
9. Continue/Recent/Downloads panel component.
10. Bottom Aang dock component.
11. Loaded-page browser frame using the same style.
12. React + Tailwind component skeleton.

## Exact Style Rules

- Dark carved stone.
- Deep green-black rail.
- Aged brass bevels.
- Muted parchment text.
- Green glow only for active/protected states.
- Mac-style window controls are part of the composition.
- The left rail must not be compressed.
- The loaded-page state must not fall back to generic browser chrome.
- Bookmark cards and medallions must be real clickable controls.
- No flat modern redesign.
- No purple/blue AI gradient.
- No pill-heavy dashboard style.

## Build Context

The live app is Electron + React + Tailwind.

Codex will implement final code. Stitch output is used for structure, measurements, and component naming.
